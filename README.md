# LancerHacks

Website for LancerHacks, the Saint Francis High School hackathon in Mountain View, CA.

## Local development

```sh
npm i
npm run dev
```

## Deploy

Upload the contents of the `dist/` folder to your web host (`public_html`). That package includes `index.html`, favicons, and the `assets/` folder used by the live site.

## Stack

- Vite
- TypeScript
- React
- Tailwind CSS
